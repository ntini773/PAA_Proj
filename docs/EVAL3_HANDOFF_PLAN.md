## 2. The project in ten lines
- PixArt-Sigma (0.6B DiT, 28 blocks, hidden 1152, head dim 72, T5 text encoder, 14 steps, CFG batch 2) run in NVFP4 on a Blackwell GPU. NVFP4 = FP4 e2m1 codes, one e4m3 scale per 16 values, plus one fp32 per-tensor scale. W4A4: weights and activations both FP4; the activation quantize step costs memory traffic.
- "Our method": a torch.compile-visible module stack (`rtx5000_next/fused_linear.py`): quantize custom op (CUDA swizzled kernel `cuda_kernels/quant2lvl_swizzled.cu`, or Triton in `quant_backends.py`) + `torch._scaled_mm`; bit-identical to torchao per layer. Levers: shared Q/K/V quantize, concat GEMM, selective bf16 layers, attention levers (text trim, cuDNN cross-attention, Sage2), limited-interval CFG, torch.compile. Static activation scale was **dropped from the method** for image quality and stays only as an ablation row.
- Baselines: bf16 compiled (bf16c), fp8 compiled, stock torchao NVFP4 compiled (stockc), torchao's own Triton quantizer (`stock_tk`, not measurable: `mslk` is a placeholder on PyPI).
- Variant strings (`variants.py` grammar) describe any setup, for example `module+be=cuda_swizzled+concat+selective+trim+xcudnn+sage2+compile`.
- Eval 3 also covers other models (SD3.5 Medium, FLUX schnell): conversion, premise checks, roofline.

## 6. How attention is kept efficient (strategy)
1. Measure first: attention share per size and model from kernel-profile class times.
2. Choose per shape, not globally: self-attention to Sage2 or the best measured kernel; cross-attention (few text keys, masked) to trim plus cuDNN/efficient; joint attention (SD3.5 head dim 64, FLUX head dim 128) to Sage2 or Sage3 at native head dims.
3. Remove waste: trim padded text tokens (exact); test native head dim 72 against padding to 96/128 (25% extra FLOPs at 96).
4. Quality gate: keep a backend only if paired LPIPS vs bf16 compiled stays inside the noise floor **at 1024 px**, not only 512.
5. Compile-safe: count graph breaks per backend (`torch._dynamo.explain`); custom-op wrapper where needed.
6. Count prep cost: Sage's INT8/FP8 quantize kernels are classed as attention time (rule added in `analysis/kernel_classes.py`), so speed-ups are end-to-end.
7. Optional compression (DiTFastAttn plans) only if it passes the same gate.
